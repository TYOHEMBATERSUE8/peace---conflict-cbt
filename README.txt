FASTEST FREE HOSTING OPTION: GITHUB PAGES

1. Create/sign in to a GitHub account.
2. Create a NEW PUBLIC repository, for example:
   peace-conflict-cbt
3. Upload the file named:
   index.html
4. Open the repository's Settings > Pages.
5. Under "Build and deployment", choose:
   Deploy from a branch
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will publish the site. The resulting address will look like:
   https://YOUR-GITHUB-USERNAME.github.io/peace-conflict-cbt/

The exact URL depends on the GitHub username you choose.
